### 🤖 [STRIDE-AI — Threat Modeling with AI](https://github.com/GustavoLimaMartins/hackathon-stride-ai)

Aplicação de IA para analisar diagramas de arquitetura cloud, detectar componentes e gerar relatórios de modelagem de ameaças com a metodologia STRIDE.

`Python` `YOLOv8` `Computer Vision` `OCR` `LLMs` `Streamlit`

### 🦟 [End-to-End Dengue Prediction](https://github.com/GustavoLimaMartins/END-TO-END-DENGUE-PREDICTION)

Pipeline de dados e Machine Learning com dados DATASUS/SINAN de 2019–2024, incluindo extração, pré-processamento, engenharia de features e classificação de notificações de dengue.

`Python` `Pandas` `Machine Learning` `Deep Learning` `Docker`

### 🏥 [Genetic Algorithm for Hospital Logistics](https://github.com/GustavoLimaMartins/GeneticAlgorithmForHospital-sLogistic)

`Python` `Genetic Algorithms` `Optimization`
